Dear [Name],

Good news — the new STRUCON website is built, and every page is in place.

**You can view it here:** https://strucon.vercel.app

Please do have a look through it before you start on the form below — seeing the pages makes it
much easier to picture where each piece of information appears. This is a private preview link
for your review; it is not visible on Google and has not replaced your existing website.

There is one step left before we can take it live: confirming the content is accurate.

### Why we need your help

To build the site, we used everything available on your current website. However, a lot of that
information appears not to have been updated for some time — as one example, the certification
shown is ISO 9001:2008, a standard that was withdrawn in September 2018.

Where no information existed at all, we wrote realistic **example text** so you could see and
review a complete, working website rather than empty pages. **That example text is not factual,
and none of it will be published.** It is a placeholder, and every instance is listed in the
attached form for you to replace.

### What we need you to do

The attached Excel file lists all 145 pieces of information, with the text currently on the
website shown next to each one.

1. Open the attachment and read the **"Read Me First"** tab.
2. Go to the **"Content Form"** tab.
3. For each row, read **column D** — this is exactly what the website says today.
4. Type the correct version in the **yellow column E**.
5. If something is already correct, simply write **OK**. If it does not apply, write **N/A**.
6. Save the file and send it back to me.

You do not need to fill in any other column, and you do not need any technical knowledge —
it is all plain text.

### Where to start

Please use the **Priority** column and complete the **49 rows marked "Critical"** first. These
are either required before the site can go live, or the text currently in place is not accurate.

The most important are:

- **Your current ISO certificate** — the site shows a version withdrawn in 2018.
- **The four headline figures** on the homepage (years, projects, engineers, countries). The
  current figures contradict each other: it says "26+ years" but also "founded 2003".
- **Three real project case studies.** The three currently on the site are invented examples we
  wrote as placeholders, with invented tonnages and clients.
- **Real client names, testimonials and leadership team details** — all are placeholders today.
- **Which clients we may name publicly**, and which must remain anonymous under NDA. Naming real
  clients is considerably more persuasive to prospective customers, so it is worth checking.

### Files to send separately

Please also send these by email or a shared drive link — they do not go in the spreadsheet:

- **Logo** in high resolution (SVG, or a large PNG with a transparent background), plus a white
  version for dark backgrounds if you have one.
- **A short video for the homepage banner** — 10 to 20 seconds, no sound, no captions. Steel
  erection, a plant, or a 3D model walkthrough all work well.
- **Photographs** — completed projects, your offices, and headshots of the leadership team.
- **Company profile PDF** — the website has a "Download Company Profile" button that needs it.
- **Client logos** — only those you have permission to display.

### One legal point

The Privacy Policy and Terms of Use pages currently contain standard drafts. These must be
reviewed by your legal advisor before the site goes live — we are not able to provide legal
advice on them.

If any row is unclear, or you would prefer to work through it together on a call, I am very happy
